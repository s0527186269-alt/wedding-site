# אתר הזמנות + פאנל ניהול — הוראות התקנה

## מה יש כאן
- `public/hazmana.html` — תבנית ההזמנה עצמה. **זהו העותק היחיד של התבנית**: כל שינוי בו משתקף מיד בתצוגה המקדימה, בהורדה ובכתובת החיה.
- `public/panel-nihul.html` — פאנל הניהול, בו יוצרים ועורכים לקוחות
- `functions/` — הקוד שרץ בענן (Cloudflare) ומדבר עם מסד הנתונים ועם אחסון התמונות
- `schema.sql` — מבנה מסד הנתונים

לאחר ההתקנה: הפאנל יהיה בכתובת `/panel-nihul.html`, וכל הזמנה מפורסמת תעלה בכתובת `/i/<slug>`.

## התקנה (הכל דרך האתר, בלי טרמינל)

1. **גיטהאב** — צרי ריפוזיטורי חדש וריק ב-github.com. לחצי "Add file" ← "Upload files", וגררי לתוכו את כל התיקייה הזו (חשוב לשמור על מבנה התיקיות: `public/`, `functions/`, `schema.sql`).

2. **Cloudflare Pages** — בלוח הבקרה של Cloudflare, תחת "Workers & Pages", לחצי "Create" ← "Pages" ← "Connect to Git", ובחרי את הריפוזיטורי שיצרת. בהגדרות ה-Build:
   - Build output directory: `public`
   - (אין צורך בפקודת build)

3. **מסד הנתונים** — תחת "Storage & Databases" ← "D1", לחצי "Create database" ותני לו שם. אחר כך, בטאב "Console" של המסד, הדביקי את התוכן של `schema.sql` ולחצי הרצה — זה יוצר את הטבלאות.

4. **אחסון התמונות** — תחת "R2", לחצי "Create bucket" ותני לו שם (למשל `wedding-media`). **אין צורך להגדיר אותו כציבורי** — התמונות מוגשות דרך הכתובת `/f/...` של האתר עצמו.

5. **חיבור המסד והאחסון לאתר** — בהגדרות פרויקט ה-Pages, תחת "Bindings" (או "Settings" ← "Functions"), הוסיפי שני חיבורים:
   - D1 binding בשם `DB`, מחובר למסד שיצרת
   - R2 binding בשם `MEDIA`, מחובר ל-bucket שיצרת

6. **סיסמת ניהול** — באותו מקום, תחת "Environment variables" (או "Secrets"), הוסיפי משתנה בשם `ADMIN_KEY` עם סיסמה שתבחרי (רצוי מחרוזת אקראית וארוכה).

7. **התראות במייל (אופציונלי)** — כדי שכל ברכה חדשה תישלח למייל:
   - היכנסי ל-brevo.com ופתחי חשבון חינמי (300 מיילים ביום, בלי כרטיס אשראי).
   - תחת Settings ← "Senders, domains, IPs" ← Senders, הוסיפי את כתובת המייל שלך כשולח. Brevo ישלח אליה קוד בן 6 ספרות; הזיני אותו וזהו. **אין צורך בדומיין.**
   - תחת Settings ← "SMTP & API" ← API Keys, צרי מפתח חדש.
   - באותו מקום שבו הגדרת את `ADMIN_KEY`, הוסיפי:
     - `BREVO_API_KEY` — המפתח שיצרת
     - `NOTIFY_FROM` — כתובת השולח שאימתת (חייבת להיות בדיוק אותה כתובת)
     - `NOTIFY_EMAIL` — הכתובת שאליה יגיעו הברכות כברירת מחדל
   - בפאנל, תחת "ברכות מהאורחים", אפשר להגדיר כתובת שונה לכל לקוח בשדה "התראה במייל" — למשל המייל של הזוג עצמו. היא גוברת על `NOTIFY_EMAIL`.
   - אם לא תגדירי את `BREVO_API_KEY` — הכל ימשיך לעבוד בדיוק כמו קודם, פשוט בלי מיילים.

8. **פריסה מחדש** — אחרי הוספת ה-bindings וה-secret, בצעי "Retry deployment" (או דחפי שינוי קטן לגיטהאב) כדי שההגדרות ייכנסו לתוקף.

9. גשי לכתובת `https://<הפרויקט-שלך>.pages.dev/panel-nihul.html`. בפעם הראשונה תתבקשי להזין את סיסמת הניהול — היא נשמרת בדפדפן כך שלא תצטרכי להזין אותה שוב.

## איך זה עובד
- בפאנל את יוצרת/עורכת לקוח ולוחצת "שמירה" — זה נשמר ישירות במסד הנתונים.
- **לקוח חדש צריך שמירה אחת לפני העלאת תמונות** — השמירה היא שיוצרת עבורו את המקום באחסון.
- תמונות מוקטנות אוטומטית בדפדפן ואז עולות ל-R2; במסד נשמרת רק הכתובת שלהן. לכן ההזמנה נטענת מהר גם ברשת סלולרית.
- בסקשן "מוזיקה" אפשר להעלות קובץ שמע מהמחשב, בדיוק כמו תמונה, או להדביק קישור חיצוני. העלאת קובץ דורסת את הקישור שהיה שם.
- לוחצים "פרסום ההזמנה" כדי שהיא תהיה זמינה בכתובת הציבורית `/i/<slug>`.
- אפשר לשנות את כתובת ההזמנה גם אחרי שמירה — השורה והברכות עוברות לכתובת החדשה, והישנה נמחקת. שימי לב שקישור שכבר נשלח ללקוח יפסיק לעבוד.
- כשאורח ממלא את טופס הברכה, הברכה נשמרת במסד. "ברכות שהתקבלו" פותח עמוד מסודר עם כל הברכות של אותו לקוח, עם כפתורי הדפסה (או שמירה כ-PDF) והורדה כקובץ טקסט. אם הוגדרו התראות במייל, כל ברכה נשלחת גם למייל ברגע שהיא מתקבלת.
- כפתורי "פתיחת מפה" ו-"פתיחת Waze" משתמשים בשדה "כתובת לניווט". במחשב הם נפתחים באתר, ובטלפון באפליקציה אם היא מותקנת. אם השדה ריק, נלקחת השורה האחרונה של "מידע 1".
- כפתור "שמרו ביומן" מוריד קובץ `.ics` תקני לפי "תאריך היעד", באורך ארבע שעות ועם תזכורת יום מראש. אם אין תאריך תקין, הכפתור לא מוצג.
- "הורדת ההזמנה" מורידה קובץ HTML עצמאי. שימי לב: בקובץ הזה התמונות מקושרות לאתר שלך, כך שהוא דורש חיבור לאינטרנט.
- מחיקת לקוח מוחקת גם את הברכות שלו וגם את התמונות שהעלית עבורו.

## אבטחה — חשוב
דף הפאנל (`/panel-nihul.html`) נגיש לכל מי שיודע את הכתובת, אך כל פעולת שמירה/מחיקה/העלאה/צפייה בברכות דורשת את `ADMIN_KEY`.

מומלץ להוסיף שכבה נוספת: ב-Cloudflare תחת "Zero Trust" ← "Access" ← "Applications", הגדירי אפליקציה על הנתיב `/panel-nihul.html` והרשי כניסה רק לכתובת המייל שלך. זה חינם עד 50 משתמשים וחוסם את הכניסה לדף עצמו.

## מגבלות שכדאי להכיר
- תמונות: גודל מרבי 8MB (לפני ההקטנה האוטומטית). סוגים נתמכים: JPG, PNG, WebP, GIF, SVG.
- מוזיקה: גודל מרבי 20MB. סוגים נתמכים: MP3, M4A, OGG, WAV. הקובץ עולה כמו שהוא בלי דחיסה, ולכן כדאי להעדיף MP3 סביר במשקל (128–192kbps) כדי שההזמנה תיטען מהר בנייד.
- התוכנית החינמית של D1 מוגבלת ל-500MB מסד ול-5GB אחסון בחשבון — הרבה מעבר למה שדרוש כאן.
