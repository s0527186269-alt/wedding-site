# אתר הזמנות + פאנל ניהול — הוראות התקנה

## מה יש כאן
- `public/hazmana.html` — תבנית ההזמנה עצמה
- `public/panel-nihul.html` — פאנל הניהול, בו יוצרים ועורכים לקוחות
- `functions/` — הקוד שרץ בענן (Cloudflare Workers) ומדבר עם מסד הנתונים
- `schema.sql` — מבנה מסד הנתונים

לאחר ההתקנה: הפאנל יהיה בכתובת `/panel-nihul.html`, וכל הזמנה מפורסמת תעלה בכתובת `/i/<slug>`.

## התקנה (הכל דרך האתר, בלי טרמינל)

1. **גיטהאב** — צרי ריפוזיטורי חדש וריק ב-github.com. לחצי "Add file" → "Upload files", וגררי לתוכו את כל התיקייה הזו (חשוב לשמור על מבנה התיקיות: `public/`, `functions/`, `schema.sql`).

2. **Cloudflare** — בלוח הבקרה של Cloudflare, תחת "Workers & Pages", לחצי "Create" → "Pages" → "Connect to Git", ובחרי את הריפוזיטורי שיצרת. בהגדרות ה-Build:
   - Build output directory: `public`
   - (אין צורך בפקודת build)

3. **מסד הנתונים** — עדיין בלוח הבקרה, תחת "Storage & Databases" → "D1", לחצי "Create database" ותני לו שם. אחר כך, תחת הטאב "Console" של המסד, הדביקי את התוכן של `schema.sql` ולחצי הרצה — זה יוצר את הטבלאות.

4. **חיבור המסד לאתר** — בהגדרות פרויקט ה-Pages שלך, תחת "Bindings" (או "Settings" → "Functions"), הוסיפי D1 binding: משתנה בשם `DB`, מחובר למסד שיצרת.

5. **סיסמת ניהול** — עדיין בהגדרות הפרויקט, תחת "Environment variables" (או "Secrets"), הוסיפי משתנה בשם `ADMIN_KEY` עם סיסמה שתבחרי (למשל מחרוזת אקראית ארוכה). זו הסיסמה שתגני עליה בפאנל הניהול.

6. **פריסה מחדש** — אחרי הוספת ה-binding וה-secret, יש לבצע "Retry deployment" (או פשוט לדחוף שינוי קטן לגיטהאב) כדי שההגדרות ייכנסו לתוקף.

7. גשי לכתובת `https://<הפרויקט-שלך>.pages.dev/panel-nihul.html`. בפעם הראשונה תתבקשי להזין את סיסמת הניהול (`ADMIN_KEY`) — היא נשמרת בדפדפן כך שלא תצטרכי להזין אותה שוב.

## איך זה עובד
- בפאנל את יוצרת/עורכת לקוח ולוחצת "שמירה" — זה נשמר ישירות במסד הנתונים.
- לוחצים "פרסום ההזמנה" כדי שהיא תהיה זמינה בכתובת הציבורית `/i/<slug>`.
- כשאורח ממלא את טופס הברכה בהזמנה, הברכה נשמרת במסד הנתונים. בפאנל, לחיצה על "ברכות שהתקבלו" מציגה את כל הברכות של אותו לקוח.
- כפתור "הורדת ההזמנה" עדיין עובד כמו קודם — מוריד קובץ HTML עצמאי, אם תרצי לשלוח קובץ ישירות ולא להשתמש בכתובת החיה.

## אבטחה — חשוב
- כרגע דף הפאנל עצמו (`/panel-nihul.html`) נגיש לכל מי שיודע את הכתובת, אך כל פעולת שמירה/מחיקה/צפייה בברכות דורשת את `ADMIN_KEY`. מומלץ בעתיד להוסיף הגנה נוספת ברמת הדומיין (למשל Cloudflare Access) כדי שגם עצם הכניסה לעמוד הפאנל תהיה מוגנת.
